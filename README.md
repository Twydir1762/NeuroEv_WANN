

# Обучение RL-агентов с использованием подхода WANN и нейроэволюции
Лабораторная работа по реализации нейроэволюционного алгоритма для поиска эффективных архитектур нейросетей, независимых от весов (подход WANN — Weight Agnostic Neural Networks), в задачах обучения с подкреплением (RL).

Проект включает в себя сравнительный анализ с базовыми методами, проведение гиперпараметрических тестов, механистическую абляцию элементов сети и оценку полученных решений в среде Gymnasium.

## 🚀Инструкция по запуску
### 1. Клонирование репозитория
```bash
git clone https://github.com/Twydir1762/NeuroEv_WANN.git
cd NeuroEv_WANN
```

### 2. Настройка окружения и установка зависимостей
Рекомендуется использовать виртуальное окружение:
```bash
# Создание виртуального окружения
python -m venv .venv

# Активация (для Windows)
.venv\Scripts\activate

# Активация (для Linux/macOS)
source .venv/bin/activate

# Установка зависимостей
pip install -r requirements.txt
```

### 3. Запуск локального сервера MLflow
Перед запуском обучения необходимо запустить сервер для логирования метрик:
```bash
mlflow server --port 5000
```

### 4. Запуск обучения и тестирования
В отдельном окне терминала (с активированным виртуальным окружением) запустить основной скрипт обучения:
```bash
python genetic_alg
```
Для проверки эффективности и визуального представления поведения агентов в среде запустить файл тестирования:
```bash
python test_ind.py
```

### 5. Визуализация динамики популяций
Для анализа результатов, построения графиков эволюции структуры, метрик качества и динамики развития особей запусти модуль визуализации:
```bash
python visualize_populations.py
```

## 📊 Содержимое исследования
В ходе работы собираются и анализируются следующие данные:
- Динамика изменения приспособленности (fitness) и усложнения топологий сетей.
- Результаты гиперпараметрического анализа и механистической абляции.
- Метрики устойчивости (робастности) агента при добавлении шума в среду или изменении начальных условий.
